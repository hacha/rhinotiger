RhinoTiger

RhinoTiger is a generative psytrance firmware for the M-VAVE FM-1, from dark psy to hi-tech. It plays by itself, and you steer it: four macro knobs, a mixer with mutes, and keys that throw one-shot sounds into the music. A rolling FM bass, percussion, a repeating line, zaps and gurgles, and an atmosphere under it all; breaks, builds and drops that come on their own or when you call them; sixteen effects to play on the keys; eight worlds, from slow and wet to fast and fine; and AUTO PLAY, which plays a whole set through them by itself.

This is version 1.1. It reads nothing another firmware saved, so back that up first. You install it at your own risk, and the installer can put M-VAVE's own firmware back.

  • Try it in the browser. Play it right here, with sound. It runs the same code as the FM-1, so you don't need one.
  • Install it from Chrome or Edge, with the FM-1 connected by USB.
  • The Manual explains the screen, the pages, the keys and the effects, the sections and the worlds.
  • Download rhinotiger-1.1.fwsc to use the command-line installer: python3 base/tools/fm1_install.py rhinotiger-1.1.fwsc (in the source).
